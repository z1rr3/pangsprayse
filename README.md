# Pangspray – informationswebbplats

Statisk, responsiv hemsida för GitHub Pages. Ladda upp `index.html` och hela mappen `assets/` i repositoryts rot. Aktivera Pages under Settings → Pages.

## Att kontrollera före publicering
- Verifiera vilka Prisjakt-ID:n som motsvarar färgad respektive ofärgad produkt.
- Verifiera påståenden om juridisk status med aktuella regler och exakt produktsammansättning. Webbplatsen påstår inte kategoriskt att alla varianter är licensfria.
- Kontrollera att tillverkarens 96 månaders funktionsgaranti gäller aktuella produkter och lagerpartier.
- Kontrollera att produktvideo och återförsäljarlänkar fungerar.
- Kontakt: kundservice@teknikproffset.se.
- Ange eventuell egen domän i GitHub Pages först när den är bestämd.
